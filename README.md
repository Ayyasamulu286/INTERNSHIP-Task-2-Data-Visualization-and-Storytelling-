# Task 2 - Data Visualization and Storytelling

## Objective

The objective of this task is to create meaningful visualizations and derive business insights from sales data using Power BI.

---

## Tool Used

* Microsoft Power BI Desktop

---

## Dataset Used

* Superstore Sales Dataset
* File: `Superstore_Cleaned.xlsx`

---

## Dashboard Components

### KPI Cards

* Total Sales
* Total Profit
* Total Orders
* Total Customers

### Visualizations

1. Category Wise Sales Analysis (Bar Chart)
2. Region Wise Sales Analysis (Donut Chart)
3. Monthly Sales Trend Analysis (Line Chart)
4. Profit by Sub-Category Analysis (Column Chart)
5. Top 10 Customers Analysis (Bar Chart)
6. Loss Making Products Analysis (Bar Chart)

---

## Key Business Insights

* Technology category generated the highest sales.
* West region generated the highest revenue.
* Copiers produced the highest profit.
* Tables category generated losses.
* Sales peaked during November and December.
* Top customers contributed significantly to overall revenue.

## Dashboard Design Principles

* Clean and professional layout
* Consistent color theme
* Business-focused insights
* Easy-to-read charts
* Minimal clutter
* Proper chart selection
